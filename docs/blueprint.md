# **App Name**: Hanumant Technology Redesign

## Core Features:

- Interactive Hero Banner: Implement a full-screen hero banner with a soft gradient background, floating line/mesh pattern, and engaging text.
- Core Values Section: Design a section showcasing core values using glassmorphic cards with line icons and subtle hover effects.
- About Us Timeline: Create a vertical timeline displaying company milestones with animated content reveal on scroll.
- Training Programs & Services: Showcase training programs and services in a grid of cards with icon highlights and optional interactive toggles.
- Student Showcase: Implement a horizontal carousel gallery featuring student profiles with success stories on hover.
- CTA Section: Design a split diagonal section with motivational text and a bold CTA button featuring a progress animation.
- Stats & Achievements: Display key stats and achievements using animated counters and line-style icons.
- Newsletter Subscription: Create a centered card for newsletter subscriptions with a clean input field and success animation.
- Footer Section: Design a multi-column corporate footer with quick links, contact info, social icons, and branch location previews.

## Style Guidelines:

- Primary color: Navy Blue (#0A2342) to symbolize trust.
- Secondary color: Sky Blue (#00A8E8) for freshness & innovation.
- Accent color: Teal (#02C39A) for growth & progress.
- Neutrals: White, Light Gray for balance.
- Headline font: 'Merriweather' (serif) for trust & vision.
- Body font: 'Inter' / 'Poppins' (sans-serif) for clarity & modern feel.
- Glassmorphism & subtle gradients.
- Clean whitespace + structured grid layouts.
- Rounded corners (lg → xl) for friendliness.
- Soft shadows + hover lift for interactivity.
- Smooth scroll-triggered fade/slide animations for sections.
- Micro hover states (links underline with animation, buttons glow softly).
- Accessibility-friendly design (high contrast, ARIA labels, keyboard navigation).
- Subtle cursor effect (soft blue halo).
- Use consistent line icons throughout the website.
